# InvoiceTrucker v1.0.0 — Initial Public Showcase

InvoiceTrucker v1.0.0 is the first public portfolio release.

## Highlights

- A responsive Next.js and React landing page with accessible newsletter
  registration
- A polished, read-only SaaS demo for trucks, drivers, clients, invoices,
  expenses, reports, documents, and settings
- Typed frontend integration with loading, empty, error, filtering, sorting,
  search, pagination, responsive tables, and mobile alternatives
- An ASP.NET Core API with explicit DTOs, validation, RFC 7807 Problem Details,
  rate limiting, CORS, health checks, and structured logging
- An EF Core and PostgreSQL model with explicit money precision, relationships,
  indexes, constraints, migrations, and deterministic fictional data
- Dockerfiles and Docker Compose for PostgreSQL, API, and frontend runtime
- Vitest, React Testing Library, xUnit integration, and Playwright end-to-end
  test coverage
- GitHub Actions CI for frontend, backend, dependency audit, and full-stack
  browser validation
- Public architecture, API, deployment, design-system, security, contributing,
  licence, code-of-conduct, and screenshot documentation

## Scope

InvoiceTrucker is a fictional, read-only portfolio showcase. All demo records
are fictional. Authentication, multi-tenancy, editing workflows, payments,
OCR/AI scanning, subscriptions, and proprietary production-product source code
are intentionally excluded.
